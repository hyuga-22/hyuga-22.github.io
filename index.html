FRONTEND / WEB · FEATURED

Flaskozi ω・´ - 顔文字辞書（Web版）

Flask × kaomozi（顔文字）+ ω・´ ／ 現在最も力を入れて開発している代表作品

PCで顔文字を入力する際、スマートフォンの「Simeji」のような辞書アプリが存在しない不便さを解消するために開発。CLI版をFlaskで作り直し、認証・セキュリティ対応を含めて一般公開できる形に発展させました。

主な機能

  • 顔文字の検索・コピー・ローカルお気に入り管理（ログイン不要）
  • 管理者による顔文字の登録・編集・削除、データのバックアップ／復元
  • Zip Slip対策、認可チェック、ブルートフォース対策などのセキュリティ対応

工夫した点

「動けばよい」実装から一歩進め、Zip Slip対策・認可チェックの一貫性・原子的なファイル書き込みなど、実運用を意識したセキュリティ課題を洗い出して対応しました。インターンシップの個別フィードバック面談でZoomの画面共有を通じて見ていただいた際には、機能面は作り込まれており、デザインさえ整えれば通常のWebサイトとして通用する完成度だとの評価をいただきました。

今後の課題

CSRFトークンによる本格的な対策やSQLiteへの移行、デザイン・UI/UXの調整が未着手のため、今後の改善点として残しています。インターンシップの個別フィードバック面談において「挨拶・笑い・反応のようなジャンルで顔文字を検索できると良い」というご意見をいただいたため、ジャンル検索機能の実装を予定しています。また、入力中のテキストを検知して顔文字候補をポップアップ表示するChrome拡張機能を実装し、PC版simejiに近い体験を将来的に目指したいと考えています。

BACKEND / DATABASE

TODO管理CLI

専門学校1年次の「データベース設計」の授業課題を、ポートフォリオ用に見直したもの。ユーザーごとにTODOを優先度・期限つきで管理できるCUIアプリです。

主な機能

  • ユーザー管理（登録・表示・更新・削除）、TODO管理（登録・表示・更新・削除・出力）
  • 優先度順／期限順での並び替え、上位5件表示／全件表示の切り替え

工夫した点

SQLをすべてパラメータ化してSQLインジェクションを防ぎ、更新・削除処理ではcommit／rollbackによるトランザクション管理を行っています。ポートフォリオ用の見直しでは、メニューが操作のたびに終了してしまう不便さを解消するためwhileループ化し、TODO表示も上位5件と全件表示を選べるように拡張しました。

今後の課題

エラーハンドリングの強化や利便性の向上、データベース設計の最適化、機能の追加・修正が挙げられます。将来的には、Flaskozi ω・´と同じようにWEB化し、共有しやすい形にすることも考えています。

API連携

天気検索アプリ

気象庁のサイトやテレビをわざわざ確認するのが面倒な時に、地域名を入力するだけで手軽に天気予報や気温を確認できるツールとして開発しました。

主な機能

  • 地域名から緯度経度への自動変換（表記ゆれにも対応）
  • 過去の天気の期間検索、今日から先の天気予報（1〜16日）の表示

工夫した点

当初はPythonで取得したデータをDBに保存し一覧表示するだけの構成でしたが、「WEB上で完結させたい」「検索するたびに履歴が溜まるのは良くない」という気づきから、DBを持たないその場検索の構成に作り直しました。「越谷市」「越谷」のような地域名の表記ゆれにも、複数パターンを自動で試すことで対応しています。

今後の課題

複数地点を同時に比較表示する機能や、気温の推移をグラフで可視化する機能は、今後の改善案として残しています。
